# Weather Dashboard


<img width="1341" height="606" alt="image" src="https://github.com/user-attachments/assets/f2034ae8-781a-4559-ae87-28ec6b9cbeaa" />




A React application that fetches real-time weather data using OpenWeatherMap API.

## Features
- Search weather by city
- Live API fetching
- Loading and error handling
- Auto refresh every 60 seconds
- useEffect for side-effect management

## Technologies
React
JavaScript
OpenWeather API
CSS
